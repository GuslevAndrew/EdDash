# Тимчасова сторінка EdDash

Режим паузи ввімкнений за замовчуванням (`lib/project-status.ts`).
Сторінка працює без бази даних. Middleware показує її і за старими
адресами розділів, а для `/api/*` повертає 503 без запуску обробників,
зокрема для автоматичного оновлення Vercel.

Вигляд: `components/home/PausedPage.tsx` та `PausedPage.module.css`.
Оригінальна головна сторінка збережена в `components/home/ActiveHomePage.tsx`.

Перед поверненням відновіть базу й підключення. Потім установіть
`EDDASH_PAUSED=false` у середовищі хостингу та виконайте нову збірку
і публікацію. Оригінальна головна сторінка та її metadata повернуться
автоматично.

Ці локальні зміни самі по собі не змінюють опублікований сайт.
Архів від 22.10.2026 зберігає стан проєкту до додавання заглушки.
